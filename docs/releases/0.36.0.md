Check a PR now says its verdict in a sentence: `/check` reads "Held back: this pull request fails 1 of 2 checks" or "Nothing fails: all 3 checks passed", announces it to screen readers, and no longer jumps while a shared link loads. "Try one" leads with a real red catch labelled with its agent, and the landing page takes a pasted link under its headline. In the editor, the verdict waits for the last check instead of changing under you. And Aperture's own pull requests now carry the **Checked by Aperture** comment, so anyone browsing the repository sees what Agent Check posts.

This release has no database migration. Nothing that Aperture Agent Check or Aperture Bot bundles changed, so Agent Check v1.10 and Aperture Bot v1.22 stay current and need no rebuild.

### Changed

- **Check a PR says its verdict in a sentence, and the editor waits for the last check.** `/check` shows "Held back: this pull request fails 1 of 2 checks" or "Nothing fails: all 3 checks passed", the editor's wording, and announces it to screen readers; a shared `?pr=` link keeps its space while it loads, so the page no longer jumps (layout shift 0.18 to 0.01 on a phone), and its smallest text is 12px. "Try one" leads with a red catch labelled with its agent (Copilot · 1 red, Tagline#43), then one clear and one to look at, and the landing page takes a pasted link under its headline. In the editor, the verdict says "Checking: 5 of 6 done, 1 failing so far" until every check is in, instead of "Held back: fails 1 of 6" that changed under you, and Composer waits too; "Make it a check" keeps its place meanwhile. The command palette highlights only the selected row (it painted every row), hover shows, and typing `>` no longer leaves an empty Files heading. A deleted line keeps its red tint as the cursor line, and the light theme's "look" colour clears 4.5:1 on its tint (was 4.39:1) ([#278](https://github.com/Hankaws/aperture/pull/278)).
- **Aperture's own pull requests carry the Checked by Aperture comment.** Its CI now runs Agent Check the way users run it, through the action's own `action.yml` with `comment: true` and `pull-requests: write`, so the inputs, the default token and the comment are tried on every pull request, and anyone browsing the repository sees what it looks like ([#280](https://github.com/Hankaws/aperture/pull/280)).
