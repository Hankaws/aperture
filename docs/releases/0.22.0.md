Your bot knows the whole project in the editor. When you summon it with Ctrl/⌘+J, it gets the path of every file and the small files the one you have open imports, and when it needs another file to answer, such as a type, a function it calls or a test, it reads that file first instead of guessing, and says which files it read. The places it names in its answers, like `src/store.ts:32`, are now links: click one and the editor opens the file with those lines picked out.

Each time it reads more files is another answer from your model, so it counts as one more run. A secret file's text is never sent.

No Aperture Bot release is needed: [v1.14](https://github.com/Hankaws/aperture-bot/releases/tag/v1.14) is current, and this release has no database migration.
